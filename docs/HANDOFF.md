## Сейчас в фокусе

**Doppler (в протоколах — D6 Cascade Reversion) — единственная живая линия.** Ловит отскок после
каскадного делевериджинга: `ΔOI_8h ≤ −15% И ΔP_8h ≤ −5%` → LONG next-open, структурный стоп
flushLow−0.5×ATR200, таймаут 72ч. Спека: `docs/strategies/doppler.md`. Название «Doppler»
утверждено автором 2026-08-23; в прегах/артефактах сохраняется id `D6-*` (трассируемость).
Статус (точная формулировка после внешнего ревью 2026-08-24): **две preregistered GO-репликации
с оговорками** — extension H24 (+1.90%, чистая) и mgmt H72-stopStruct (+2.97%, победитель из 6
co-primary рук, но GO взяли 3 из 6 — не одна ячейка) — **+ in-sample подтверждение на мажорах**
(−15/−5 контроль +3.11% [+0.38;+5.60], breadth 10/12; правило выбрано по census на той же истории —
НЕ независимая репликация) — **+ НЕ-репликация** на tp-вселенной (+0.01%) — **+ 0 живых сделок**
(форвард только начат). Итог: перспективная гипотеза, подтверждение НЕЗАВЕРШЕНО; судья — форвард
и/или девственная вселенная. **Матрёшка выходов прогнана (d6-partial): частички и безубыток НЕ
улучшают контроль — лучшая форма = контроль (хвост платит за серию).** Тейки по R — KILL ранее.
Робастность гэп-стопа (ответ на ревью): гэп-пробоев 0/118, конвенции идентичны
(`ci-results/d6-gapfill-robustness.*`). Известные артефакты учёта: pooled maxDD в results —
не хронологический (heat-подобный); ATR-скип событий без счётчика (1 шт в d6-tp). Детали:
`docs/NEGATIVE-KNOWLEDGE.md` (D6).

**Paper-forward Doppler — идёт.** `npx tsx tools/forward/d6ForwardRunner.ts`, журнал
`tmp/forward/d6/{signals.jsonl,trades.jsonl,report.md}`. 37 перпов; живой OI окном 8 суток ⇒
запуск раз в 1–3 дня (ноут постоянно не нужен). Меж-прогонный min-gap соблюдается (фикс 2026-08-23).

после ~10–15 сделок; решающий live-N — ~50+ сделок.

**Ближайший research-шаг — вселенная Б (мид-капы, данные качаются фоном).** Census-карта мажоров

разрешён; по готовности — census Б той же сеткой → сверка карт → решение о чистом подтверждении

## Стандарт издержек для прогонов (соглашение автора, 2026-08-18)

Реальное исполнение автора — вход ТОЛЬКО по рынку (taker). Net-прогоны считать в двух точках:
**(1) 0 bps** (gross — референс/потолок) и **(2) 5 bps/side** (BingX VIP0 taker — целевой сценарий).
Maker/лимитки НЕ моделируем. Спот-taker 0.1% — только «худший случай». Если фид фьючерсный —
добавлять фактический funding за фактическое удержание. Для Doppler это стандарт всех прогонов.
