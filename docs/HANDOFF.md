## Сейчас в фокусе

**Doppler (в протоколах — D6 Cascade Reversion) — единственная живая линия.** Ловит отскок после
каскадного делевериджинга: `ΔOI_8h ≤ −15% И ΔP_8h ≤ −3%` → LONG next-open, структурный стоп
flushLow−0.5×ATR200, таймаут 72ч. Спека: `docs/strategies/d6-cascade.md`. Название «Doppler»
утверждено автором 2026-08-23; в прегах/артефактах сохраняется id `D6-*` (трассируемость).
Статус: **GO ×2 репликации** (лучшая рука H72-stopStruct: +2.97%/сделку net, PF 2.03) +
**НЕ-репликация контроля на третьей вселенной** (d6-tp `KILL`, 2026-08-23: старые листинги,
контроль +0.01% против +2.97%). Причина не-репликации неизвестна, вопрос популяции открыт —
это главное research-сомнение линии (детали — `docs/NEGATIVE-KNOWLEDGE.md`, раздел D6).
Тейки по R — KILL, не переоткрывать; частички/безубыток — будущая preregistration (матрёшка рук
согласована с автором, см. ROADMAP).

**Paper-forward Doppler — идёт.** `npx tsx tools/forward/d6ForwardRunner.ts`, журнал
`tmp/forward/d6/{signals.jsonl,trades.jsonl,report.md}`. 37 перпов; живой OI окном 8 суток ⇒
запуск раз в 1–3 дня (ноут постоянно не нужен). Меж-прогонный min-gap соблюдается (фикс 2026-08-23).
Темп ~10–15 сигналов/мес; промежуточная сверка профиля с бэктестом (WR/доля стопов/MFE) —
после ~10–15 сделок; решающий live-N — ~50+ сделок.

**Ближайший research-шаг — census-карта на мажорах (данные качаются).** Диагностика БЕЗ вердиктов:
сетка провала OI −5/−8/−12/−15/−20% × цена −3/−5%, окно 8ч. Вселенная А = 12 мажоров
(BTC/ETH/SOL/XRP/BNB/DOGE/ADA/LTC/LINK/BCH/DOT/TRX); вселенная Б — мажоры + мид с порогом оборота
(порог крутится; ранг >80 разрешён автором). По карте автор утверждает правило → prereg → прогон рук.

**Линия Reversal (Apex/GGI) — закрыта терминально** (big-corpus KILL, 2026-08-22). Не трогать:
`docs/strategies/zonda-reversal.md`, `docs/NEGATIVE-KNOWLEDGE.md`.

## Стандарт издержек для прогонов (соглашение автора, 2026-08-18)

Реальное исполнение автора — вход ТОЛЬКО по рынку (taker). Net-прогоны считать в двух точках:
**(1) 0 bps** (gross — референс/потолок) и **(2) 5 bps/side** (BingX VIP0 taker — целевой сценарий).
Maker/лимитки НЕ моделируем. Спот-taker 0.1% — только «худший случай». Если фид фьючерсный —
добавлять фактический funding за фактическое удержание. Для Doppler это стандарт всех прогонов.
