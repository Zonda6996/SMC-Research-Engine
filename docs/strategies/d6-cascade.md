# D6 Cascade Reversion — спека стратегии (GO research / paper-forward)

> **Что это:** первая стратегия проекта с двумя независимыми preregistered-репликациями GO.
> Ловит отскок после каскадного делевериджинга (ликвидационная спираль на перпах).
> **Статус:** GO research; перед реальными деньгами — paper-forward.
> **Как часто меняется:** при изменении статуса/правил (только новые preregistration).

## 1. Гипотеза (механизм)

Резкое схлопывание открытого интереса вместе с ценовым флашем = принудительное закрытие плеч.
Продавцы выжаты (taker-buy ~0.47), рынок переприценён → систематический отскок в течение
12–72 часов. Это не ценовой паттерн: сигнал живёт в плечевом потоке (OI), недоступном из OHLCV.

## 2. Правило (финальная форма, заморожена протоколом d6-mgmt)

Часовой бар `i` (Binance USD-M perpetual):
1. **Событие:** `OI[i]/OI[i−8] − 1 ≤ −15%` **И** `close[i]/close[i−8] − 1 ≤ −3%`
   (OI — причинное последнее известное значение 5m-метрик ≤10 мин);
2. Не более одной сделки на символ за 8 баров (min-gap);
3. **Вход:** LONG по open бара `i+1`;
4. **Стоп:** `min(low баров i−7..i) − 0.5 × ATR200` (структурный, «идея сломалась»); внутри бара стоп проверяется первым;
5. **Выход:** close бара `entry+71` (до 72 часов), либо стоп раньше.

## 4. Практика исполнения

- Частота: **~1–9 событий/год на актив**; вселенная из десятков активов даёт несколько сигналов/мес;
- Риск на сделку = ширина до стопа (обычно 5–25% цены) × размер позиции; позиционировать так,
  чтобы стоп = заданный % счёта;
- Удержание до 72ч; позиция проходит через funding-сеттлменты (учтено в цифрах);
- **Не добавлять тесный стоп/тейк «у mean»** — канон-менеджмент убил эдж (+0.045R, KILL);
- Heat портфеля: сигналы кластеризуются (рыночные каскады бьют по многим активам разом) —
  лимитировать число одновременных позиций.

## 5. Ограничения и что дальше

- Четыре вселенные (47 символов суммарно): GO на новых листингах (×2), НЕ-репликация на
  старых листингах tp-набора, GO на мажорах (правило −15/−5 выбрано по census — in-sample
  оговорка). Картина популяции пёстрая: простые объяснения («новые/старые», «мажоры/щитки»)
  не работают; вопрос открыт;
- OI-proxy каскадов (не прямые ликвидации); покрытие метрик у части символов <100%;
- Следующий шаг: **paper-forward** на живом фиде (`tmp/forward/d6/`) + вселенная Б (мид-капы)
  для чистого подтверждения правила −15/−5; после — решение о статусе линии и реальном размере.
