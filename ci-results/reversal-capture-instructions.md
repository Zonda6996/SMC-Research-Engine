# Как собрать Reversal без мучений

Тебе не нужно вручную выписывать ATR, RSI, MFI, entry/add/stop или размеры позиции.

## Вариант A — пробная подписка и один тестовый CSV

На Free экспорт недоступен — пользователь подтвердил это 31.07.2026. Поэтому CSV можно проверить только через пробную/платную подписку.

Если решишь активировать trial:

1. На TradingView открой небольшой участок, где виден один BUY/SELL оригинального Reversal.
2. Оставь на графике Reversal и, при необходимости, Apex.
3. Выполни **Export chart data**.
4. Сразу пришли первый CSV, не выгружая всю историю.
5. Я проверю колонки:
   - если есть `BUY`, `SELL`, `Signal`, `Long`, `Short`, `Reversal`, числовой plot или иная сигнальная серия — дальше почти всё автоматизируется;
   - если есть только OHLCV/Apex lines, trial не решает разметку labels, и основной путь остаётся через упрощённые screenshots.

Официальная справка TradingView говорит, что экспорт включает отображаемые данные и индикаторы, но не гарантирует отдельные CSV-колонки для графических `plotshape`/labels. Поэтому достаточно одного тестового CSV.

## Вариант B — если labels не экспортируются

Не нужно делать 30 сложных скриншотов с уровнями.

Сделай только два типа скриншотов:

### Positive — где BUY/SELL есть

- весь график с видимой меткой;
- в верхней части должны быть видны symbol и timeframe;
- наведи курсор на свечу сигнала;
- если удобно, сделай один screenshot.

### No-signal — где похожая ситуация, но метки нет

- тот же symbol/timeframe;
- участок примерно 50–100 свечей;
- курсор на выбранной свече;
- один screenshot.

Позиционные уровни нужны только для 3–6 отдельных примеров, не для каждого сигнала.

## Как именовать файлы

Можно просто так:

```text
P01_BTCUSDT_15m_SAFE_BUY_2026-07-23_20-15.png
P02_BTCUSDT_15m_SAFE_SELL_2026-07-24_12-15.png
P03_SOLUSDT_5m_SAFE_SELL_2026-07-25_06-50.png
N01_SOLUSDT_5m_NO_SIGNAL_2026-07-20_12-00.png
N02_SOLUSDT_5m_NO_SIGNAL_2026-07-20_15-00.png
```

Если не хочется переименовывать, можно прислать всё одним пакетом и написать одним сообщением:

```text
1 positive BTC 15m Safe BUY 23.07 20:15
2 positive ...
3 no-signal SOL 5m 20.07 12:00
```

## Минимальный пакет

Для первой финальной попытки достаточно:

- 8 positive screenshots;
- 8 no-signal screenshots;
- 2–4 Safe/Risk/Standard A/B сравнения;
- 1 тестовый CSV TradingView после trial — только если хочешь проверить автоматизацию.

Если CSV не содержит сигнальные колонки, он не обязателен: можно сразу прислать screenshots. Это уже удобнее, чем прежние 30–36 полностью размеченных случаев.

## Что не нужно делать

- не выписывай RSI/Stochastic/MFI вручную;
- не выписывай OHLCV вручную;
- не снимай entry/add/stop для каждого случая;
- не собирай данные по десяткам активов сразу;
- не трать время на дизайн;
- не выгружай большую историю сразу после активации trial — сначала один маленький тестовый CSV.

## Про пробную подписку

Пробную подписку имеет смысл брать только как короткий эксперимент:

1. сначала открыть экспорт на текущем аккаунте;
2. если кнопки нет — проверить trial;
3. экспортировать небольшой участок с одним простым индикатором и Reversal;
4. открыть CSV здесь и проверить колонки;
5. только после этого выгружать большую историю.

Если CSV содержит только OHLCV, trial не решит задачу полностью: labels Reversal всё равно придётся размечать скриншотами. Если CSV содержит числовой plot сигнала — это резко упрощает реконструкцию, и тогда screenshots нужны только для проверки label timing и режимов.
