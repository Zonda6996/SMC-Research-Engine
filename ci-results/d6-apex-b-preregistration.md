# D6-apex-B — preregistration (FROZEN): три определения «входа в зону Apex» на вселенной Б

> Заморожено до reveal (2026-08-24, решение автора: «apex варианты давай сделаем»).
> Вселенная Б (16 мид-капов census, ≥20k баров) — на этих символах apex-классы РАНЕЕ НЕ
> СЧИТАЛИСЬ (свежие для зоны). Пороги/режимы события виделись в census Б как точечные оценки —
> in-sample оговорка остаётся; классы зоны — свежие.

## 1. Данные и события

- 16 мид-капов Б (1000PEPE/AAVE/ARB/AVAX/BOME/ENA/ENS/ICP/LDO/ONDO/OP/STX/SUI/TRB/ZEC/ZEN),
  1h, полная история, `data/d6-apex-b/manifest.json` (SHA `e877614c…`).
- Событие (1h): `ΔOI(8ч) ≤ −15% И ΔP(8ч) ≤ −5%` (STANDARD) **или** `≤ −20% / ≤ −5%` (SAFE);
  оба режима объединяются в общий пул; gap 8ч; OI причинно на открытие бара (≤10 мин).

## 2. Зона и три класса (co-primary)

Полосы: `computeApexBands` (канонический движок, каузально, дефолтные параметры), полоса
сигнального бара `i`; entryOpen = open бара `i+1`; `depth = (greenHi − entryOpen)/(greenHi − greenLo)`.

| # | класс | условие |
|---|---|---|
| 1 | `deep` | entryOpen ≤ greenHi И depth ≥ 0.5 (приор из d6-apex на мажорах) |
| 2 | `inner` | entryOpen ≤ greenHi (вход во внутреннюю зону, любая глубина) |
| 3 | `mean` | entryOpen ≤ mean (вход ниже средней линии) |

## 3. Сделка (одинаковая у всех классов)

Стоп `min(low окна 8ч) − 0.5×ATR200`, внутри бара стоп первым; таймаут close[entry+71];
reclaim НЕТ. Net 5bps/сторону + фактический funding. Без полного горизонта — исключение со счётом.

## 4. Гейки

- Три co-primary теста: `mean(net|класс) − mean(net|комлемент)` на общем пуле событий,
  UTC-day cluster bootstrap CI95 (10k, seed **25082026**; дни ресэмплятся целиком).
- Вердикт варианта: `GO` ⇔ lower95 > 0 при N_класса ≥ 100; иначе `INCONCLUSIVE DATA`;
  `KILL` ⇔ мощность есть, lower95 ≤ 0.
- Варианты независимы друг от друга; комплемент у `deep`/`inner`/`mean` разный — тесты
  перекрываются, это осознанное co-primary (как 6 рук в d6-mgmt).

## 5. Терминальность

Reveal один раз; Б сожжена для D6-apex-классов. Другие определения — новые preregistration
на новых данных.
