# RE12c — вендор-сырая таксономия (ETH/SOL 2h), partial+add, без full-fix-at-mean, только safe

**Причина RE12c:** RE12b давал partial=0% и stop-rate 38%/33% из-за неверного сопоставления исходов движка с корзинами вендора (Partial считался как мёртвый исход `partial-be`; `partial-stop` шёл в Stop). Здесь классификация — по СЫРЫМ ярлыкам, как в таблице автора (задано автором, §2.1): грубо stop / take(fullfix) / partial; **частичка→стоп у вендора = Partial и WIN**.

> §2.2: движок `src/core` НЕ тронут — правится только классификатор в research-раннере. base `{fullFixAtMean:false, addEnabled:true}`, mode `safe`. Стоп калибруется под vendor stop-rate по V-WIN-определению (полные стопы без частички / терминальные). Экономика (totalR/meanR/PF) — по `netR` движка, от версии таксономии не зависит.

**Версии классификации:** `V-WIN` (по автору: FullFix=full-tp; Partial=взята частичка и не дошли до полной цели, включая частичка→стоп, = WIN; Stop=полный стоп без частички). `V-STRICT` (вилка снизу: частичка→стоп относим к Stop).
