# D6-apex — preregistration (FROZEN): фильтр «глубоко в зоне Apex» для каскадных входов

> Заморожено до reveal (2026-08-24, решение автора). Гипотеза автора: каскадный вход несёт
> прибыль только при совпадении с зоной Apex — вход «глубоко внутри» нижней полосы; входы
> вне зоны слабы/отрицательны (census `ci-results/d6-apex-scalp.*` уже видел классы —
> **in-sample оговорка**; этот prereg формализует фильтр с гейтами).
> Механика каскада — как в d6-multitf (окно 8ч, стоп структурный, чистый таймаут 72ч —
> reclaim удалён по данным d6-multitf/d6-partial).

## 1. Данные и события

- 12 мажоров, ряды всех ТФ из `data/d6-multitf/manifest.json` (SHA `8e172fc4…`), funding оттуда же.
- События: каскад 8ч — `ΔOI(8ч) ≤ −15% И ΔP(8ч) ≤ −5%` (STANDARD) и `≤ −20% / ≤ −5%` (SAFE),
  на каждом ТФ ∈ {5m, 15m, 30m, 1h, 2h, 4h}; gap 8ч; OI причинно на открытие бара (≤10 мин).

## 2. Зона и классификация входа

- Полосы: `computeApexBands` (канонический движок, каузальные, дефолтные параметры) на барах
  данного ТФ; берётся полоса сигнального бара `i`.
- `depth = (greenHi − entryOpen) / (greenHi − greenLo)`, entryOpen = open бара `i+1`.
- **Класс IN-ZONE-DEEP:** `entryOpen ≤ greenHi` И `depth ≥ 0.5`. Остальные события — комплемент.

## 3. Сделка (одинаковая у обоих классов)

Стоп `min(low окна 8ч на ТФ) − 0.5×ATR200(ТФ)`, внутри бара стоп первым; таймаут
close[entry + 72ч/ТФ − 1]; reclaim НЕТ. Net 5bps/сторону + фактический funding.
Сделки без полного горизонта исключаются со счётом.

## 4. Первичная гипотеза и гейты

- **Один первичный тест:** объединённая по всем ТФ×режимам разность
  `mean(net | IN-ZONE-DEEP) − mean(net | комплемент)`, UTC-day cluster bootstrap CI95
  (10k, seed **25082026**, дни ресэмплятся целиком — оба класса вместе).
- **GO_filter ⇔ lower95 > 0** при ≥100 событиях в объединении и ≥100 в IN-ZONE-DEEP,
  иначе `INCONCLUSIVE DATA`.
- Вторично (дескриптивно, без гейтов): таблицы по каждому ТФ×режим×класс; доля сделок в классе.

## 5. Терминальность

Reveal один раз; мажоры сожжены для D6-apex-конфлюэнса. Другие определения глубины/зоны —
только новые preregistration.
