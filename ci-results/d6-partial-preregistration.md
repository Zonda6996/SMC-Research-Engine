# D6-partial — preregistration (FROZEN): частички и безубыток против контроля

> Заморожено до прогона reveal (2026-08-23). Вопрос: улучшают ли частичные тейки и перевод
> остатка в безубыток торговую форму каскадной руки. Событие и стоп — линия D6.
> ⚠ Честная оговорка: правило события (−15%/−5%) выбрано автором по census-карте мажоров
> (`ci-results/d6-census-majors.*`, in-sample к этой истории). Предмет сравнения — РУКИ ВЫХОДА
> на одинаковых событиях, не подтверждение сигнала. Подтверждение сигнала — вселенная Б / форвард.

## 1. Вселенная и событие

- 12 перпов-мажоров: BTC/ETH/SOL/XRP/BNB/DOGE/ADA/LTC/LINK/BCH/DOT/TRX (USDT-M, 1h, полная
  история с листинга; ряды как в census — окна считаются в БАРАХ ряда, пропуски часов биржи
  фиксируются манифестом без выбраковки, консистентно с картой).
- Событие: `OI[i]/OI[i−8] − 1 ≤ −15%` И `close[i]/close[i−8] − 1 ≤ −5%`; OI — причинное последнее
  известное значение 5m-метрик ≤10 мин; min-gap 8 баров; LONG по open бара `i+1`.

## 2. База сделки (все руки) и руки

- Стоп: `flushLow(бары i−7..i) − 0.5 × ATR200`; внутри бара СТОП ПЕРВЫМ.
- Таймаут: close бара `entry+71` (72ч). Сделки без полного горизонта исключаются механически
  со счётом. `riskDist = entryOpen − stopLevel`.

| # | имя | частичка | безубыток остатка |
|---|---|---|---|
| 1 | `C-H72` (контроль) | нет | нет |
| 2 | `P1R` | 50% по TP = entryOpen + 1×riskDist | нет |
| 3 | `P1R-BE` | 50% по TP = entryOpen + 1×riskDist | стоп остатка → entryOpen |
| 4 | `P15R` | 50% по TP = entryOpen + 1.5×riskDist | нет |
| 5 | `P15R-BE` | 50% по TP = entryOpen + 1.5×riskDist | стоп остатка → entryOpen |

- Интрабар-порядок (консервативный): (1) стоп: low ≤ текущий стоп остатка → выход ПО ЦЕНЕ СТОПА
  (частичка на этом баре не считается), (2) частичка: high ≥ TP → 50% по цене TP (лимитное
  допущение), однократно, (3) безубыток активируется ПОСЛЕ бара касания — со следующего бара.
- Funding за фактическое удержание: сеттлементы до бара частички — вес 1.0, начиная с бара
  частички — вес 0.5 (остаток позиции).

## 3. Экономика

- Net % fixed-notional на полный объём входа: вход 5bps + выходные колена суммарно 5bps
  (частичка 50% по TP + остаток по стопу/таймауту) + funding по весам выше. Gross@0 дескриптивно.

## 4. Гейки и правило лучшей руки

- Power gate: ≥100 событий суммарно, иначе `INCONCLUSIVE DATA`.
- Каждая рука: pooled mean net%, UTC-day cluster bootstrap CI95 (10k, seed **25082026**);
  GO_arm ⇔ lower95 > 0; breadth положительных символов отчётывается.
- Лучшая рука: среди GO-рук с breadth ≥9/12 — максимальный CI-low (как в d6-mgmt §4).
- Диагностика MFE на контроле: доли сделок с ходом ≥1R / ≥1.5R / ≥2R / ≥3R до выхода
  (диагностическая метрика, на гейты не влияет).

## 5. Терминальность

Reveal один раз; эти 12 символов с этим правилом сожжены для D6-класса. Другие доли/уровни
частички и иные механизмы — отдельные будущие preregistration на новых данных.
